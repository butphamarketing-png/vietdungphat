# Việt Dũng Phát — giao diện mới

Website giới thiệu Công ty TNHH Kiến trúc Xây dựng Việt Dũng Phát, làm lại theo phong cách atelier châu Âu. Hình ảnh và nội dung bài viết lấy từ site gốc [vietdungphat.com](http://vietdungphat.com/).

```bash
npm install
npm run scrape   # đồng bộ dự án, sản phẩm, dịch vụ, tin tức
npm run dev
```
